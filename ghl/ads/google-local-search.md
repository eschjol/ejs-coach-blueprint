# Google Search Ads — GHL / Google Ads

Autopilot tier. Landing page = Intro funnel. Call extension → GHL number (missed call text-back).

---

## Campaign type

Search — high-intent local keywords

---

## Keywords (phrase match)

```
"golf lessons {{city}}"
"golf instructor {{city}}"
"golf instructor near me"
"beginner golf lessons {{city}}"
"private golf lessons {{city}}"
"junior golf lessons {{city}}"
"golf coach {{city}}"
```

## Landing page

Intro funnel URL — `{{booking_url}}`

## Negative keywords

```
free golf tips

driving range only

```

---

## GHL integration

**Call from ad →** missed call → WF-02 text-back  
**Form extension (if used) →** WF-01  
**Tag paid leads →** `ads-google`

---

## Budget

Start $20–30/day. Scale when cost-per-intro-booking is acceptable (target: under $40–60 per booked intro in competitive markets).
